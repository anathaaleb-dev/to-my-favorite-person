HAPPY BIRTHDAY — LUTHFIYAH ♡

CARA MENJALANKAN
1. Ekstrak file ZIP ini.
2. Buka folder happy_birthday_luthfiyah.
3. Klik dua kali index.html untuk membuka website di browser.

CARA MENAMBAHKAN FOTO KE ALBUM
- Klik salah satu kartu album di website.
- Pilih foto dari laptop/komputer.
- Foto akan tampil di kartu album selama halaman itu dibuka. Untuk foto permanen bagi semua pengunjung, letakkan foto di folder website dan ubah kartu album di index.html/style.css.

CARA MEMASANG BACKSOUND
- Siapkan musik MP3 yang kamu punya izin untuk menggunakannya.
- Ganti nama file menjadi: music.mp3
- Letakkan file music.mp3 di folder yang sama dengan index.html.
- Klik tombol “Putar musik” di kanan atas. Browser memang memerlukan klik pengguna sebelum musik boleh diputar.

FILE
- index.html : struktur halaman dan ucapan
- style.css  : tampilan pink-putih, animasi, layout
- script.js  : musik, album foto, tombol, dan konfeti
- music.mp3  : tempat meletakkan file backsound milikmu (belum disertakan)
